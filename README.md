# SoundMess

Музыкальный сервис на Django: каталог треков и релизов, личная медиатека и публикация музыки. Плеер продолжает воспроизведение при переходах между страницами.

## Возможности

- Поиск музыки с фильтрами по жанру, настроению, темпу и году выпуска.
- Плеер с очередью, перемоткой, повтором и прогрессом воспроизведения в фоне панели.
- Любимые треки, приватные плейлисты, сохранённые релизы и история прослушиваний.
- Подписки на артистов, лента публикаций и комментарии с таймкодами и ответами.
- Кабинет артиста: загрузка аудио, обложек и текстов, создание релизов, статистика прослушиваний.
- Панель модерации: проверка публикаций, управление комментариями, пользователями и балансами.
- Адаптивный интерфейс для компьютеров и телефонов.

Музыку можно слушать без регистрации. Для публикации нужно получить статус артиста и отправить треки на модерацию. Изменения опубликованного трека требуют повторного одобрения.

Кошелёк и поддержка артистов работают с виртуальными средствами. Реальных платежей нет.

## Технологии

Python 3.12+, Django 6.0.3, SQLite, Django Templates, CSS и JavaScript. Для обработки изображений используется Pillow, для проверки аудио — Mutagen. Сборка фронтенда не требуется.

## Запуск

```bash
git clone https://github.com/4Zepar/SoundMess.git
cd SoundMess/my_app
```

Windows / PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver
```

Linux / macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver
```

Сервис доступен по адресу [localhost:8000](http://127.0.0.1:8000/). Все команды Django выполняются из папки `my_app`.

Для создания администратора выполните `manage.py createsuperuser` через Python из виртуального окружения. Панель управления находится по адресу `/moderation/`, Django Admin — `/admin/`.

При первом запуске каталог пуст. Можно загрузить свою музыку или создать тестовый каталог командой `manage.py seed_demo --with-sample-audio`. Команда запросит пароль для тестовых аккаунтов.

## Данные и настройки

База SQLite и загруженные файлы из `my_app/media/` хранятся локально и не входят в репозиторий. При переносе существующего каталога их нужно скопировать отдельно.

Настройки задаются переменными окружения; пример — [my_app/.env.example](my_app/.env.example). Перед размещением на сервере задайте `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS` и `DJANGO_DEBUG=False`.
